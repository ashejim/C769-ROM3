# Task 2 (Proposal) Section Map

**Task description:** A proposal for an IT project that was approved by the instructor in Task 1. The proposal identifies a problem and proposes an IT solution, including a methodology for project development and an implementation plan. Task 1 must pass before Task 2 can be submitted.

**Tense:** Future tense — Task 2 describes a project to be completed.

**Critical guidance:**
- The rubric is mostly a checklist. Missing a single objective item can get the submission returned.
- Provide required content in a format easily identified and matched to the requirements.
- Use paragraphs with complete sentences for most sections. Tables are acceptable for F1 and G.
- Do NOT write an outline.
- All checkboxes (`❑`) in the official template indicate objective items — every one must be addressed.

**Sections:**
- A — Proposal Overview
  - A.1 Problem Summary
  - A.2 IT Solution
  - A.3 Implementation Plan
  - A.3.a Justification of Plan
- B — Review of Other Work
  - B.1 Works Informing Design

- D — Current Project Environment
- E — Methodology
- F — Project Goals, Objectives, and Deliverables
  - F.1 Goals, Objectives, and Deliverables Table
  - F.2 Goals, Objectives, and Deliverables Descriptions
